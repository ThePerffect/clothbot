# ClothBot: гардероб и стилист в Telegram

Вы фотографируете одежду, бот вырезает её из фона, определяет цвета и каждый день собирает
сочетаемые образы с учётом погоды. Он считает, сколько раз вы надели вещь, и сам отправляет её в «грязное».

Работает двумя способами:

* **Mini App**: основной интерфейс. Карусель образов, гардероб с фильтрами, стирка, профиль.
  Подстраивается под светлую и тёмную тему Telegram.
* **Чат-бот**: присылаете фото и выбираете категорию кнопками. Есть `/today`, `/laundry` и утренняя рассылка образа.

## Возможности

| | |
|---|---|
| ✂️ **Вырезка фона** | Нейросеть [BiRefNet](https://github.com/ZhengPeng7/BiRefNet) (через `rembg`), затем доочистка маски: убираются мусорные островки (пара обуви при этом сохраняется), заполняются дырки, сглаживается край, убирается цветная кайма фона (defringe). Вещь кадрируется по контуру и центрируется. |
| 🎨 **Цвета** | k-means в пространстве CIE Lab, названия цветов «как в магазине» (деним, кэмел, хаки…), автоопределение принта. |
| 🗂 **Категории** | 8 категорий и около 50 подкатегорий. У каждой подкатегории задана теплота, формальность, норма носок до стирки и комфортный диапазон температур. |
| ✨ **Образы** | Поиск по лучу. Оценка учитывает гармонию цветов (нейтральная база + акцент, тон-в-тон, аналоговые и комплементарные пары), единство стиля, погоду, правило «один принт», свежесть и ротацию вещей. Учатся на ваших ❤️/👎. Варианты подбираются разными (MMR). |
| 🌦 **Погода** | Open-Meteo, бесплатно и без ключа. Город задаётся командой `/city` или геолокацией. |
| 🧺 **Стирка** | «Надену» увеличивает счётчик носок. Когда он доходит до нормы (футболка — 1, джинсы — 6, можно настроить), вещь становится грязной. Дальше путь «Грязное → В стирке → Чистое», грязное в образы не попадает. |
| 🎯 **Образ вокруг вещи** | Выбираете вещь и получаете образы, собранные вокруг неё. |
| ⏰ **Утренний образ** | `/morning 8`: бот сам присылает коллаж образа дня в 8:00 по вашему времени. |

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Mini App работает только по **HTTPS**. Для локального запуска подойдёт туннель:
   ```bash
   cloudflared tunnel --url http://localhost:8080   # выдаст https://xxx.trycloudflare.com
   ```
   На сервере поставьте перед приложением любой reverse-proxy с TLS (Caddy, nginx).
3. Настройте окружение:
   ```bash
   cp .env.example .env   # впишите BOT_TOKEN и WEBAPP_URL
   ```
4. Запустите:
   ```bash
   docker compose up -d --build
   # или без Docker:
   python -m venv .venv && . .venv/bin/activate
   pip install -r requirements.txt
   python -m clothbot
   ```

При первом запуске скачивается модель вырезки (около 900 МБ для `birefnet-general`) и кладётся в `data/models`.
На CPU одна вещь обрабатывается за 5–15 секунд, процессу нужно примерно 3 ГБ RAM. На слабом сервере
поставьте `REMBG_MODEL=birefnet-general-lite` или `isnet-general-use`.

Бот сам регистрирует команды и кнопку меню «Гардероб», которая открывает Mini App.

### Отладка Mini App в браузере

Задайте `DEV_USER_ID=1` в `.env` и откройте `http://localhost:8080/app/`. Запросы без подписи Telegram
будут выполняться от имени этого пользователя. **В продакшене эту переменную не задавайте.**

## Как снимать вещи

* Раскладывайте вещь целиком на ровной однотонной поверхности, контрастной к ней.
* Снимайте при дневном свете, без вспышки и сверху.
* В чат лучше отправлять фото **файлом**: Telegram сжимает обычные фото, а файл приходит в полном качестве.
  В Mini App фото загружаются без сжатия.

## Устройство проекта

```
clothbot/
  catalog.py   категории, подкатегории и их свойства
  colors.py    Lab/LCh, палитра, именованные цвета, правила сочетаемости
  stylist.py   генератор образов (beam search + функция оценки + MMR)
  imaging.py   вырезка (BiRefNet + доочистка маски), коллаж для чата
  db.py        SQLite: пользователи, вещи, образы, веса предпочтений
  services.py  общая логика для бота и API
  api.py       HTTP API Mini App (Starlette) и раздача статики
  auth.py      проверка подписи initData Telegram
  bot.py       чат-бот (long polling)
  tg.py        минимальный клиент Bot API
  weather.py   Open-Meteo
webapp/        Mini App (HTML/CSS/JS без сборки)
tests/         unittest
```

Тесты:

```bash
python -m unittest discover -s tests -t .
```

Тесты не требуют тяжёлых зависимостей: вместо вырезки подставляется фейковый процессор,
вместо Telegram используется фейковый клиент.
